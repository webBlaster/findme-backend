# Environment Variables

Configuration for the Geolocation Broadcast System can be set via environment variables.

## Available Variables

### PORT

- **Description**: The port the server listens on
- **Default**: `8000` (development), `8080` (production/fly.io)
- **Type**: Number
- **Example**: `PORT=3000`

### NODE_ENV / DENO_ENV

- **Description**: Environment name (optional, for reference)
- **Values**: `development`, `production`
- **Example**: `DENO_ENV=production`

## Fly.io Configuration

When deploying to fly.io, the `PORT` is automatically set to `8080` in `fly.toml`:

```toml
[env]
  PORT = "8080"
```

You can override this in your `fly.toml` or via:

```bash
flyctl secrets set PORT=9000
```

## Local Development

For local development, the default port (8000) is used:

```bash
# Use default port (8000)
deno task start

# Or specify a custom port
PORT=3000 deno task start
```

## Environment-Specific Configuration

### Development

```bash
PORT=8000 deno task dev
```

### Testing

```bash
PORT=9000 deno task test
```

### Production (fly.io)

Automatically uses `PORT=8080` as configured in `fly.toml`

## Setting Secrets on Fly.io

For sensitive configuration, use Fly.io secrets:

```bash
# Set a secret
flyctl secrets set MY_SECRET=value

# View all secrets
flyctl secrets list

# Remove a secret
flyctl secrets unset MY_SECRET
```

Then reference them in your code via `Deno.env.get("MY_SECRET")`
